# shadps4-from-ps4

A tool that allows you to play games on shadps4, straight from your PS4.
Using this tool, you dont need to dump the whole game to another disk, but assets are streamed from your console (except for a few files, but still a rather big difference in total size). This works by creating a FTP connection between your system and your PS4.
> [!NOTE]
> Although not mandatory, it is reccomended that your system is connected to the ps4 with an ethernet cable for reliability.

## Requirements
1. A jailbroken PS4
2. A linux system

## Guide
1. Jailbreak your PS4 (GoldHen reccomended) and start the included FTP server
2. Start one of your games
3. Clone the project locally
4. Inside that project download [curlftpfs](https://curlftpfs.sourceforge.net/) 
5. Set the files as executables
